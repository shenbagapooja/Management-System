A simple console-based banking system created to practice Core Java and object-oriented programming concepts.

**Features:**

* Create account
* View account details
* Deposit money
* Withdraw money
* Check balance
* Handle multiple accounts

**Concepts Used:**

* Classes and Objects
* Arrays
* Loops
* Switch statements
* Methods
* Exception handling
* Scanner

**Technology Used:**

* Java
