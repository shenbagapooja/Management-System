# 📚 Library Management System

A simple **Library Management System** built using Python.

This mini project allows users to manage books through a simple
command-line menu.

## 🚀 Features

1. Add a book
2. View books
3. Search for a book
4. Delete a book
5. Borrow a book
6. Return a book
7. Exit the program

## 🛠️ Technologies Used

- Python
- Lists
- Functions
- If/Elif/Else
- While Loop
- Try/Except
